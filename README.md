# TxFlow

TxFlow is an evolving transaction-processing platform built in Go.

The project is being developed as a production-oriented backend and distributed-systems project rather than as a tutorial application.

## Current stage

Initial project setup and transaction domain model.

## Planned areas

- Go concurrency
- Worker pools
- HTTP APIs
- PostgreSQL
- Redis
- Messaging
- Idempotent processing
- Observability
- Distributed systems
- Reliability and fault handling

## Running locally

```bash
go run ./cmd/txflow
